# MyFirstConsoleCppRPG
Simple C++ Console RPG with hero teams, boss raids, healing mechanics, and random events. Built with OOP principles and CMake.

Core Features:
- Squad management: Team creation with 3 custom named heroes[cite: 3, 4].
- Battle system: Boss raids with team health and damage calculation[cite: 13, 14].
- Hero progression: XP system and level-ups that increase maximum HP[cite: 1, 10].
- Equipment: Weapon system with attack damage modifiers[cite: 5, 8, 10].
- Game locations: Battle Arena, Infirmary for healing, and Forest for random events[cite: 8, 13].

Technical Stack:
- Language: C++20[cite: 11].
- Architecture: Object-Oriented Programming (classes, encapsulation, vectors)[cite: 1, 4, 7, 8, 9].
- Build system: CMake[cite: 11].

Run Instructions:
1. Clone the repository.
2. Open in CLion or any CMake-supported IDE[cite: 11].
3. Build and run main.cpp[cite: 2, 11].
